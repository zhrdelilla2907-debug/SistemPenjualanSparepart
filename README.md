## Deskripsi
Aplikasi Sistem Penjualan Sparepart dibuat menggunakan Java untuk membantu proses pengelolaan data sparepart.

## Fitur
- Login
- Tambah data sparepart
- Edit data sparepart
- Hapus data sparepart
- Pencarian data
- Transaksi penjualan

## Teknologi
- Java
- Visual Studio Code

## Cara Menjalankan
1. Buka project di VS Code.
2. Jalankan Main.java.
